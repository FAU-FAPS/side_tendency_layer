# Gazebo models

`person_walking` and `table_marble` are used by `worlds/ST_test_world_obj.world` (Figure 6a of
the paper). Both are unmodified copies from the
[Gazebo model collection](https://github.com/osrf/gazebo_models), licensed under
[CC BY 3.0](https://creativecommons.org/licenses/by/3.0/):

| Model | Author |
|---|---|
| `person_walking` | Marina Kollmitz, created with MakeHuman |
| `table_marble` | Ian Chen, Open Source Robotics Foundation |

Unused texture variants of `person_walking` are left out.
